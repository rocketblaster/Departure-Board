# Departure Board

This is a departure board with scheduled Light rail arrivals. Data came from Puget Sound One Bus Away. I created this for fun because I kept clicking on the transit agency's website for scheduled arrivals. Oh I also use OneBusAway sometimes. I'm hoping to make this personalized using the data there as well. Right now I have the basic scheduled arrival system setup.
